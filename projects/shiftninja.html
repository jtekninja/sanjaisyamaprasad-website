ShiftNinja AI

AI-powered shift readiness and recovery support for overnight workers—designed to reduce cognitive load, simplify recovery, and make the next useful action easier to see.

ShiftNinja AI is an active product project built around one central question: how can software reduce the amount of thinking an exhausted overnight worker has to do after or around a shift?

The product problem

Overnight work can create a difficult combination of sleep disruption, decision fatigue, competing responsibilities, and recovery needs. ShiftNinja is designed to turn that complexity into a smaller number of clear, practical next actions rather than another dashboard that demands attention.

Readiness instead of information overload

The product direction includes a readiness score that brings together signals such as sleep, stress, workload, hydration, and recovery. The goal is not to present more raw data; it is to use structured state to help the user understand what matters most now.

AI Today Plan and Copilot

ShiftNinja includes an AI-generated daily plan and conversational copilot. The planning flow can organize recovery-oriented actions such as sleep windows, caffeine timing, hydration, meals, naps, commute cautions, and task priorities into a simpler daily view.

Low-cognitive-load workflows

A core design principle is reducing unnecessary interaction. Quick logs, task simplification, one-primary-recommendation views, and structured AI outputs are intended to let a tired user make progress with fewer decisions and less navigation.

Application architecture

The current stack uses Next.js 16, React, TypeScript, Tailwind CSS, Framer Motion, Supabase PostgreSQL, Prisma ORM, Supabase Auth, OpenAI integration, Zod validation, Zustand state management, Stripe subscriptions, and PostHog analytics.

Product systems

The project includes protected onboarding and dashboard flows, sleep and shift logs, biometric inputs, readiness history, task workflows, AI services, feature gates, subscription logic, and placeholders for wearable integrations. The engineering challenge is keeping those systems connected without making the interface feel heavy.

Current status
