ShiftNinja AI

An application direction for turning scheduling and coordination problems into clearer, more manageable workflows.

View development repository ↗

ShiftNinja AI is part of my exploration of practical automation: taking a repetitive coordination task and giving it a simpler interface, clearer states, and more useful next actions.

The product idea

The intended direction is a planning tool that helps users reason about schedules, changes, and handoffs without turning the workflow into a spreadsheet exercise.

Engineering direction

The public repository uses a modern web stack including Next.js, TypeScript, Supabase/PostgreSQL, Prisma, Supabase Auth, and OpenAI API integrations. The design goal is to keep structured state visible and use AI only where it can translate messy context into a useful suggestion.

Current direction

This project is in development. Current work focuses on converting the scheduling model into a focused workflow, reducing coordination overhead, and keeping the user in control of final decisions.
