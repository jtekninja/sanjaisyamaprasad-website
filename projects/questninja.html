QuestNinja

An adaptive learning platform that turns long-term progression into structured pathways, measurable mastery, and a clear next challenge.

QuestNinja is an active software product centered on adaptive learning architecture. The product organizes progression into connected pathways while combining assessment, practice, feedback, mastery state, and a persistent learner profile.

The product problem

Many learning applications treat lessons, quizzes, progress, and feedback as separate experiences. QuestNinja is designed around a connected progression model: establish a starting point, surface the appropriate challenge, record performance, update mastery, and use that state to guide what comes next.

Structured progression

The interface makes progression visible through pathways and milestone-based stages rather than presenting an unstructured library of activities. That product model creates a clearer relationship between current work, demonstrated mastery, and future challenges.

Assessment and mastery state

The engineering direction includes diagnostics and assessment logic, persistent progress, and mastery tracking. These features require the application to maintain meaningful state across sessions instead of treating each exercise as an isolated interaction.

AI-assisted practice and feedback

AI is used as part of the learning workflow rather than as the entire product. The application can use AI-assisted interactions where contextual explanation or feedback is useful while keeping authentication, user state, progression, validation, and persistence in deterministic application code.

Application architecture

The development repository uses Next.js, React, TypeScript, MongoDB with Mongoose, authentication, OpenAI integration, schema validation, and automated testing with Vitest and Playwright. The project also includes progressive-web-app support and mathematical rendering.

Product engineering focus

My work on QuestNinja spans the progression model, authenticated experience, persistent profiles, assessment flows, responsive interface, AI integration, validation, testing, and the product architecture required to keep those pieces working as one system.
